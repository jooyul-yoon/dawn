# Dossier Map

All 60 questions are in `questions.py`. Each dossier mixes event recognition
with situation analysis: the player has to read a problem, not only recall a
date.

| Code name | Event | Main ideas |
| --- | --- | --- |
| THE CLOSING WINGS | Battle of Cannae | encirclement, flanks, cavalry, formation, supply depot |
| MUD AND LONGBOWS | Battle of Agincourt | mud, narrow ground, longbows, defensive position, congestion |
| THE LONG RETREAT | French Invasion of Russia | logistics, Moscow, political goals, distance, winter |
| EYES IN THE SKY | Battle of Britain | radar, fighter control, early warning, air superiority |
| THE BROKEN CODE | Battle of Midway | codebreaking, reconnaissance, carriers, timing, surprise |
| TIDES OF SURPRISE | Incheon Landing | tides, channels, sea walls, reconnaissance, operational surprise |

## A good new question

1. Start with a situation, not the event name.
2. Give one extra clue that makes the answer fair.
3. Write three believable but clearly wrong alternatives.
4. Finish with a one- or two-sentence debrief explaining why the clue matters.
